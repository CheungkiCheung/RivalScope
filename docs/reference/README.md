# Reference Design Drafts

This directory keeps older detailed design drafts from the RivalScope planning
process.

These files are useful background material, but they are no longer the source
of truth for execution order or module priority. The canonical plan is:

- [../master-plan.md](../master-plan.md)

Use these reference drafts when implementing a specific subsystem, such as
confidence scoring, provenance, DAG orchestration, role contracts, knowledge
schema, or evaluation. If any detail conflicts with the master plan, follow the
master plan.
